## 常驻负责人

工作室保持八个常驻角色：一个总负责人和七个部门负责人。临时专家只在任务需要时启用。

| 常驻角色 | 主要责任 | 收口结论 |
|---|---|---|
| 工作室总负责人 | 固定范围、分级风险、分派部门、解决冲突、汇总证据 | 工作室是否完成 |
| 产品与验收部负责人 | 固定需求、非目标、优先级、场景与验收条件 | 产品范围是否闭环 |
| 系统架构部负责人 | 审查边界、接口、依赖、数据流、容量和技术债 | 技术方案是否合理 |
| 车端协议部负责人 | 审查 ROS/C++、HTTP/WS、route、状态、单位和车型语义 | 车端契约是否可信 |
| 功能安全部负责人 | 审查危险、急停、锁定、限速、看门狗、降级和恢复 | 安全风险是否可接受 |
| AI 语音部负责人 | 审查 ASR、NLU、LLM、TTS、语料、性能和降级 | AI 交互是否达标 |
| 应用工程部负责人 | 审查后端、前端、任务流、会话和实现质量 | 软件实现是否可维护 |
| 质量与发布部负责人 | 审查测试、HIL、真车、ARM、部署、回滚和发布材料 | 证据是否支持发布 |

## 部门定义

| 部门 | 按需成员 | 必要输入 | 必须输出 | 职责边界 |
|---|---|---|---|---|
| 产品与验收部 | 需求分析、叉车业务、现场操作、文档专家 | 原始需求、用户反馈、现有验收 | 用户故事、非目标、验收条件、追踪关系 | 不决定底层技术，不降低安全要求 |
| 系统架构部 | API、数据、性能、可靠性架构专家 | 产品边界、两仓现状、质量属性 | 方案比较、组件边界、接口决策、影响面 | 不替代模块实现或安全签署 |
| 车端协议部 | C++、ROS、控制、传感器、路径规划、车型专家 | Jarvis 源码、接口状态、车辆参数 | 协议契约、单位、状态机、兼容与联调结论 | 不以 Mock 注释替代车端源码或实测 |
| 功能安全部 | 风险分析、现场安全、故障注入、网络安全专家 | 动作链路、危险场景、现有保护 | 危险清单、安全约束、降级策略、否决结论 | 不负责产品优先级；可阻止不安全交付 |
| AI 语音部 | 声学 ASR、NLU、LLM 评测、TTS/音频专家 | 噪声场景、语料、硬件指标、交互目标 | 指标、语料集、模型方案、降级和评测结果 | 不让概率模型直接绕过确定性安全层 |
| 应用工程部 | FastAPI、任务流、Vue、WebSocket、UX 专家 | 已批准方案、接口契约、验收条件 | 代码、配置、迁移、模块测试和实现说明 | 不自行改变需求、协议或安全策略 |
| 质量与发布部 | QA、E2E、契约、HIL、真车、ARM、运维专家 | 验收矩阵、变更差异、测试环境 | 测试报告、证据等级、部署与回滚结论 | 不把未执行验证标记为通过 |

## 临时专家池

按任务启用以下专家，不把所有专家固定加入每次开发：

- 前端 UX 专家：监控、配对、语音条、地图和流程编辑器。
- 任务流专家：Schema、分支、并行、暂停、恢复、断网和快照。
- ROS/C++ 控制专家：JMode、JAction、设备驱动、规划和实时行为。
- 车端协议专家：JWebHttpServer、JWebService、状态与 route 契约。
- ASR 声学专家：热词、噪声、端点、RTF、麦克风和 ARM 推理。
- NLU/LLM 评测专家：规则、槽位、复合指令、黄金语料和降级。
- TTS/音频专家：Piper、提示音、打断、播放兼容和车载声学体验。
- 功能安全专家：危险分析、急停、看门狗、锁定和故障恢复。
- HIL/真车专家：台架、车辆、车型参数、现场证据和问题复现。
- ARM/部署专家：RK3588、离线依赖、systemd、性能、日志和回滚。
- 网络安全与隐私专家：鉴权、令牌、日志、离线边界和数据保留。
- 技术文档专家：需求、架构、API、话术、用户手册和测试报告。

## 评审与签署

部门负责人必须对本部门产物给出以下一种结论：

| 结论 | 含义 | 后续动作 |
|---|---|---|
| 通过 | 范围内证据充分，无阻塞风险 | 允许进入下一门禁 |
| 有条件通过 | 结论可用，但有明确限制或待办 | 登记条件、责任人和关闭门禁 |
| 驳回 | 方案不合理、证据不足或风险不可接受 | 返工，不得进入下一门禁 |

每份签署至少记录评审范围、依据、发现、风险等级、验证证据、未验证项和交接条件。

执行成员不得评审自己的实现。部门负责人直接参与实现时，必须由另一个受影响部门负责人交叉复核；安全相关成果至少由功能安全部负责人独立签署。跨部门任务必须取得全部受影响部门负责人的结论，总负责人只能在必需签署齐全且 P0/P1 风险关闭后完成总收口。
