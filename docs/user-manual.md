## 1. 快速上手

1. 打开前端页面（core 托管或独立部署），首页显示配对卡片 [图]
2. 点"显示/刷新配对码"，输入 6 位配对码 → "确认配对" [图]
3. 右下角"现场解锁"：输入车端显示的一次性现场码 → "解锁"（被占用可"强制抢占"）[图]
4. 按住"按住说话 (PTT)"说指令，或用车载通道先说"玖物玖物"唤醒

## 2. 语音指令大全

### 2.1 点动（需现场解锁）

| 动作 | 说法示例 |
|------|----------|
| 前进 | "前进"、"往前"、"走吧" |
| 后退 | "后退"、"往后"、"倒车" |
| 左转/右转 | "左转"、"往左"；"右转"、"向右" |
| 停止 | "停止"、"停下"、"急停"（任何时候都可用） |

### 2.2 调速

"加速"/"快一点"、"减速"/"慢点"、"速度调到35"、"50%"。

### 2.3 货叉

"升起货叉"/"升一点"、"放下货叉"/"低一点"、"升到150毫米"、"升到15厘米"、"货叉调到210"。
大幅度调整（超过 100mm）会先问"当前叉高X毫米，确认升/降到Y毫米吗"，答"确认"才执行。

### 2.4 原地旋转

"原地转90度"、"左转45度"、"掉头"（=180°）。

### 2.5 点到点 / 取货

"从A点到B点"（会问"确认执行：从a点到b点吗"）；"盲叉取货"（会先追问起点、终点）；
"识别栈板"/"相机取货"（相机自动识别栈板叉取）。

### 2.6 充电

"回充"/"去充电"（回充电桩）；"去1号充电桩充电"（指定桩）。

### 2.7 任务流控制

"执行取货演示流程"（名字记不清说近似的也行，会二次确认）、"暂停任务"、"继续任务"、"取消任务"。

### 2.8 问答

"电量多少"、"什么模式"、"位置在哪"、"叉高多少"、"电机使能"、"速度多少"、"当前任务"、
"告警/报警"（报状态）、"为什么停"/"怎么回事"（给原因和处置建议）。

### 2.9 系统

"确认/好/是的"（应答追问与确认）；"取消/算了"（放弃当前对话）；"停止"（立即停车）。

## 3. 追问对话示例

### 3.1 盲叉取货（参数追问）

```
我：盲叉取货
车：请告诉我起点
我：A点
车：请告诉我终点
我：B点
车：确认执行：从a点到b点并取货吗
我：确认
车：好的，从a点到b点   （开始执行）
```

### 3.2 货叉大幅调整（安全确认）

```
我：升起货叉
车：当前叉高75毫米，确认升到210毫米吗
我：取消
车：好的，已取消
```

### 3.3 任务流二次确认

```
我：执行取货演示
车：确认执行任务流取货演示流程吗
我：确认
车：好的，开始执行取货演示流程
```

追问超过 30 秒没回答会自动放弃（"已超时，任务取消"）。

## 4. 任务流编辑器

- 打开：Dashboard 右下角"任务流编辑器"按钮，或地址栏 `#/flow`。
- 左侧点按钮加节点（货叉升降/原地旋转/点到点/栈板取货/充电/定时点动），拖到画布摆位置。
- 从节点右侧拖到下一节点左侧连线，默认绿色"成功"分支；**点击连线**切换为红色虚线"失败"分支。每个节点每类出边只能有一条。
- 选中节点，右侧参数面板编辑（带 * 为必填，黄色"安全关键"标签为安全参数；灰色小字是缺省时系统的追问话术）。
- 顶栏：填流程名 → 保存；下拉可加载已有流程；执行/暂停/继续/取消按钮控制引擎；右上角徽标显示引擎状态。
- 运行中画布只读（不能拖/连/删/改参数），节点外圈颜色实时显示状态：灰=待执行、蓝闪=执行中、绿=成功、红=失败、黄=暂停、淡灰=跳过。

## 5. FAQ

1. **说话没反应？** 车载通道要先说"玖物玖物"唤醒（30 秒内连续对话不用再唤醒）；PTT 通道不用唤醒但要先配对。
2. **提示"失败：未现场解锁"？** 点动/货叉/任务指令需要先"现场解锁"（右下角按钮输入现场码）。
3. **提示"任务流执行中，无法下发运动指令"？** 有任务流在跑，先"取消任务"或等它结束；"停止"和问答不受影响。
4. **急停后指令不执行？** 急停触发会自动退出现场模式，排除险情后需要重新现场解锁。
5. **识别错了？** 系统内置指令词纠偏表（如"掂量"→"电量"）和唤醒词同音字容差；说慢一点、用 2.2 节示例说法命中率最高。
6. **TTS 没声音？** 浏览器首次需要一次点击交互才允许播放音频（autoplay 限制）；仍无声时系统会自动回退浏览器朗读。
7. **"确认"没反应？** 确认只在有追问/待确认任务时有效，且 30 秒内有效。
8. **任务流名字说错了？** 系统会按相似度匹配；如果有多个相似流程会报出候选名让你说完整名称。
9. **流程执行中车不动了？** 可能触发了低电量保护（<20% 自动暂停并去充电），充到 80% 后人工"继续任务"恢复。
10. **断网了会怎样？** 任务流会自动续跑（网络恢复后重发当前节点），超过约 5 秒断连才判节点失败。
