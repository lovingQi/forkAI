# 闸门 A 验收清单（点动可演示）

前提：jarvis 可用（或 mock 控制失败时至少链路通）；`npm run dev:speech` + `dev:gateway` + `dev:web`。

1. 打开网页，生成配对码并确认配对 → 显示已配对。
2. 点「现场解锁」，输入车端现场码（顶栏旁/对话框显示）→ 现场点动已解锁。
3. 文本调试通道选 PTT，发送「前进」→ TTS/字幕「好的，前进」；地图有运动（有实车时）。
4. 2 秒内不发新运动指令 → 看门狗自动停（日志「看门狗停车」）。
5. 发送「快点」/「慢点」→ 调速确认话术。
6. 发送「停止」或点红「停」→ 「已停止」。
7. 结束现场后发「前进」→ 「失败：未现场解锁」；「停止」仍可用。

# 闸门 B/C 验收清单（V1 完成）

1. 未现场解锁：发送「电量多少」→ 回报电量。
2. 发送「去XXX」→ 触发 goto（站点名需地图存在）。
3. 第二设备配对后强制抢占现场 → 原设备失去点动权。
4. 车身码 URL 带 `?v=&site=` 打开后可走解锁。
5. 车载通道选 cabin：先「玖物，玖物」应声「在」，再「前进」。
