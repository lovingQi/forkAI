## 场景与语义

| 项 | 决策 |
|----|------|
| 主线 | B+C+D；一号场景 B 近场点动 |
| 运动 | 启停式 + 护栏（唤醒/现场武装、看门狗、硬停优先、速度封顶） |
| 现场 | 扫码/一次性码解锁，TTL 默认 45min（30–60 档） |
| 分级 | 运动仅现场；远程可任务/问答，不可点动 |
| 通道 | 车载常听+「玖物，玖物」；手机/电脑 PTT；现场解锁后 PTT 可直接运动 |
| 停 | 任意已配对端可下发；规则直达；≠ 实体急停 |
| 点动锁 | 单会话，后来者可 force 抢占 |
| 访问 | 配对码；点动另需现场码 |
| 选车 | 车身码深链 + 手动 IP 兜底 |
| UI | 监控总览 + 语音条；不搬激光/避障 |
| 词表 | 前后左右停 + 调速；不做货叉升降（可查叉高） |
| 任务 | 回充/空闲/停 + 试点 goto |
| 问答 | 车况只读 + 少量当前告警解释 |
| ASR/意图 | 全离线 ASR + 规则意图 |
| 看门狗 | 可配置，默认 2.0s |
| 验收 | 完成=C；排期先 A 再 B/C |

## 语音体验

| 项 | 决策 |
|----|------|
| 人设 | 冷静女声、普通话、少情绪、偏快 |
| 话术 | 短句模板；失败加原因 |
| 通道 | 点动以车载为主；问答以操作端为主 |
| 成败 | 同一音色；失败略慢 + 可选提示音 |
| 合成 | 车载离线 TTS 实时合成 |
| 唤醒 | 车载应声「在」；PTT 不应声 |
| 语言 | 仅普通话 |

## 两闸

- **闸门 A**：配对 → 现场解锁 → 点动/调速/停 → 看门狗 → TTS → 地图可见运动
- **闸门 B/C**：远程问答；goto 试点；车身码；抢占
